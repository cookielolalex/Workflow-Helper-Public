# Contributing

1. Keep changes within the CAD workflow-capture purpose.
2. Do not add generalized desktop surveillance or productivity scoring.
3. Add or update a versioned contract when an exchanged payload changes.
4. Preserve the distinction between observed behavior and validated rules.
5. Run `python scripts/validate.py` before opening a pull request.
6. Never use real client or employee data in fixtures.

Architecture changes that affect the privacy boundary require an ADR in
`docs/adr/` and explicit review.
